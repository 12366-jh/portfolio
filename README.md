# 个人作品集网站

一个纯手工构建的单页个人作品集网站，用于展示个人简介、技能标签、项目经历和联系方式。

## 功能简介

- **左侧固定侧栏**：头像、姓名、个人定位、简介、技能标签、锚点导航和版权信息
- **右侧主内容区**：Hero 展示、项目作品、关于我、联系方式四个板块
- **项目作品展示**：4 个项目卡片，采用「大图特色」「左右分栏」「反向分栏」三种布局交替排版
- **深浅色主题**：一键切换并记住用户选择
- **响应式适配**：桌面端显示固定侧栏，移动端切换为顶部导航栏

## 技术栈

| 分类 | 说明 |
| --- | --- |
| 结构 | HTML5 语义化标签（`aside` / `main` / `section` / `article` / `nav`） |
| 样式 | CSS3 自定义属性（变量）、Flexbox、Grid、媒体查询、过渡动画 |
| 脚本 | 原生 JavaScript（IIFE 模块化，无第三方库） |
| 依赖 | 无框架、无 UI 组件库、无构建工具、零依赖 |

## 运行方式

**方式一：直接打开**

双击 `index.html` 即可在浏览器中查看。

**方式二：本地静态服务器（推荐）**

```bash
# 在项目根目录执行
python -m http.server 8123
```

然后访问 <http://localhost:8123>。

> 说明：部分浏览器在 `file://` 协议下会限制 `localStorage`，此时「记住主题选择」功能可能失效（代码已做兼容处理，不会报错）。使用本地服务器可避免该问题。
>
> 页面中的配图通过在线图片接口加载，需要联网才能正常显示。

## 主要功能

### 1. 深浅色主题切换

- 页面右上角固定一个圆形切换按钮（太阳/月亮图标）
- 点击后在浅色与深色主题间切换，背景、文字、边框等颜色同步变化
- 通过 `localStorage` 的 `portfolio-theme` 记住上一次选择，刷新后自动恢复
- 主题基于 `<html>` 上的 `data-theme="dark"` 属性控制，颜色统一定义在 CSS 变量中

### 2. 移动端菜单

- 小屏设备下显示顶部栏和汉堡按钮，点击展开/收起导航菜单
- 点击菜单项或菜单外部区域会自动收起

### 3. 导航滚动高亮

- 滚动页面时，侧栏导航会自动高亮当前所在板块
- 滚动到页面底部时固定点亮最后一个导航项

### 4. 滚动渐入动画

- 项目卡片进入视口时淡入上移
- 基于 `IntersectionObserver` 实现；浏览器不支持时自动降级为直接显示
